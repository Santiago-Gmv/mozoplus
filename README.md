# 📱 Mozo Plus

## Descripción General

**Mozo Plus** es una plataforma integral en desarrollo diseñada para facilitar y gestionar la vida de los mozos. La aplicación proporciona un ecosistema completo que integra una **aplicación móvil**, un **programa de escritorio** y una **API** para optimizar las operaciones y mejorar la productividad.

---

## 🏗️ Arquitectura del Proyecto

El proyecto se compone de tres componentes principales:

### 📲 Aplicación Móvil
- Interfaz intuitiva para los mozos
- Gestión de tareas y servicios en tiempo real
- Seguimiento de ubicación y disponibilidad
- Acceso a historial de trabajos e ingresos
- Notificaciones de oportunidades laborales

### 💻 Programa de Escritorio
- Panel de control y administración
- Gestión integral de usuarios y mozos
- Reportes y estadísticas detalladas
- Configuración de servicios y tarifas
- Supervisión de operaciones en tiempo real

### 🔌 API
- Backend centralizado que conecta los sistemas
- Autenticación y seguridad
- Procesamiento de datos y lógica de negocio
- Integración de pagos y transacciones
- Manejo de bases de datos

---

## ⚙️ Funcionalidades Principales

✅ **Gestión de Trabajos**
- Publicación y asignación de tareas

- Perfiles de mozos con verificación
